# Поиск медиа файлов в home

## Сборка приложения:
- mkdir build
- cd build
- cmake ..
- make

## Использование приложения:
Приложение принимает следующие аргументы:
- --dir=<путь до каталога> - переназначает каталог, в котором ищутся медиа-файлы (по умолчанию приложение ищет в домашнем каталоге пользователя, как того требует тз).
- --period=<время в секундах> - указывает, сколько времени приложение ожидает до следующего сканирования каталога
- --recursive - сканировать подкаталоги (по умолчанию не сканируются)
- --web - выдавать JSON по GET-запросу (по умолчанию JSON записывается в файл ~/.media_files)

Например, чтобы сканировать каталог ~/Documents и отдавать JSON по GET-запросу, требуется выполнить
`./mediasearcher --web --dir=~/Documents`
